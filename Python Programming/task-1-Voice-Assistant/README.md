# Python Voice Assistant

## Project Overview

A Python-based voice assistant that listens to spoken commands and responds using voice.

## Features

- Voice input using SpeechRecognition
- Responds to "Hello" with a predefined greeting
- Tells the current time
- Tells the current date
- Performs Google web searches
- Handles speech recognition errors gracefully
- Provides text-to-speech responses using pyttsx3

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
