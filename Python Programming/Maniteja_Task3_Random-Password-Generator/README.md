# Random Password Generator

## Task 3 - Python Programming

### Objective
Build a Python tool that generates strong and random passwords based on the user's desired length.

### Features
- Generates random passwords.
- Allows the user to choose the password length.
- Uses uppercase and lowercase letters.
- Includes numbers and special characters.
- Ensures a minimum password length of 4 characters.

### Technologies Used
- Python
- `random` module
- `string` module
