# Task 5 - Chat Application

## Objective

A real-time two-user command-line chat application built using Python sockets and threading.

## Technologies Used

- Python
- socket
- threading
- datetime

## Features

- Server listens for incoming client connections
- Multiple clients can connect to the server
- Real-time bidirectional messaging
- Username support
- Timestamped messages
- Graceful client disconnection
- Disconnect notification
- Runs on the same machine using localhost
